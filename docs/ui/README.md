# Ảnh tham khảo giao diện

Quy ước tên file theo màn hình ở [08-ui-ux.md](../08-ui-ux.md):

| File | Màn hình |
| --- | --- |
| `home.png` | Trang chính (chưa hỏi) |
| `results.png` | Hội thoại + bảng kết quả |
| `compare.png` | Ngăn so sánh |
| `product.png` | Chi tiết sản phẩm |
| `lists.png` | Danh sách mua |
| `alerts.png` | Cảnh báo giá |
| `admin.png` | Quản trị thu thập |
| `ref-*.png` | Ảnh tham khảo khác; ghi chú thích điểm gì ngay trong bảng dưới |
